AI 工具入門

Antigravity & Gemini CLI 快速入門

整理第一次使用 Google Antigravity 與 Gemini CLI 時最常卡住的幾件事：安裝、網路、設定同步，以及 Rule 與 Skill 檔案該放在哪裡。

邱數恩 Grace 2026 年 4 月 23 日 閱讀時間約 4 分鐘

1. 安裝 Antigravity

  • 下載網址：https://antigravity.google/
  • 在企業網路中使用時，需要先申請開通以下網域：
    • https://antigravity.google
    • https://open-vsx.org

可使用的模型

安裝完成後，登入 Google（Gmail）帳號即可開始使用。撰文時可選的模型包括：

  • Gemini 3.1 Pro（High／Low）
  • Gemini 3 Flash
  • Claude Sonnet 4.6（Thinking）、Claude Opus 4.6（Thinking）
  • GPT-OSS 120B（Medium）

模型清單會隨版本更新，請以實際畫面為準。更完整的操作可參考官方的 Antigravity Course。

2. 同步 VS Code 的設定與套件

  1. 按下 Ctrl + Shift + P（Windows／Linux）或 Cmd + Shift + P（Mac）開啟命令面板。
  2. 輸入並執行 Import VS Code settings，即可把既有的設定與擴充套件帶過來。

推薦套件：在擴充套件市集搜尋 Antigravity Quota (AGQ) 或 Antigravity Quota Watcher，可以即時監控各模型的使用配額，避免用到一半才發現額度不足。

3. 重要檔案與路徑

項目路徑
Rule（全域規則）C:/Users/xxx/.gemini/GEMINI.md
Skill（全域）C:/Users/xxx/.gemini/antigravity/skills
Skill（單一專案）~/.agent/skills

4. 使用 Gemini CLI

Gemini CLI 讓你在終端機直接與 Gemini 協作，適合習慣命令列、或想把 AI 串進腳本流程的人。入門教學可參考 CodeLove 的 Gemini CLI 教學。

5. Skill 在不同 AI 工具中的位置

同一個專案若同時使用多種 AI 工具，各工具讀取技能（Skill）設定的資料夾不同，放在專案根目錄下即可分別生效：

專案根目錄下的資料夾對應的 AI 工具
.agentAntigravity
.geminiGemini CLI
.githubGitHub Copilot

把技能依工具分開放，切換工具時就不必重新整理設定，團隊成員也能直接沿用。
